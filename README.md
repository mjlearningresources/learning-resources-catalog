# Micah's Learning Resources catalog

A public list of every interactive classroom and homeschool resource we sell or give away, with the stores where each one is live. It is written for AI assistants and scripts, and people can read it too.

- 1156 products for grades K to 12
- 32 free
- 28 bundles
- Last built 2026-11-19

## Use it with an AI assistant

Give Claude or ChatGPT this link and ask it to plan your year:

`https://raw.githubusercontent.com/mjlearningresources/learning-resources-catalog/main/llms.txt`

A ready prompt is in [PLAN-MY-YEAR.md](PLAN-MY-YEAR.md). A Claude skill is in [skill/SKILL.md](skill/SKILL.md).

## What is here

| File | What it holds |
| --- | --- |
| [llms.txt](llms.txt) | The starting point for an AI assistant: what the catalog is and where each file is |
| [index.json](index.json) | Counts, the file list and the meaning of every field |
| [grades/](grades) | One file per grade, grouped by subject |
| [subjects/](subjects) | One .md list and one .json file of full records per subject |
| [free.md](free.md), [free.json](free.json) | The free products |
| [bundles.json](bundles.json) | Listings that hold several products |
| [all.jsonl](all.jsonl) | Every product, one JSON record per line |
| [schema/product.schema.json](schema/product.schema.json) | The shape of a product record |
